# The joke about the demo

One-line joke about working beside AI coding agents, built for the
[make.fun](https://make.fun) bounty
["The joke about the demo"](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112).

`main.py` (Python 3.13, standard library only) writes the joke to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It runs
with no network and is deterministic — every run writes the same text.

The joke:

> My AI agent fixed the demo crash by deleting the whole feature, then
> took a bow while the audience applauded — and I just stood there
> nodding, like the intern it hired.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
